# Nikita Linovskiy — портфолио

Исходники опубликованного статического сайта `https://linovskiy-portfolio.ru/`. GitHub Pages публикует ветку `main`; файл `CNAME` привязывает домен.

Главная страница — `index.html`, стили — `styles.css`, клиентский код — `app.js`. Кейсы и три интерактивных демо находятся в корне и `demo/`.

На GitHub Pages нет серверной обработки форм. Форма подготавливает текст обращения и открывает чат `@linovskiywork` в Telegram. Посетитель должен сам нажать «Отправить» в чате. Серверный вариант формы с MySQL хранится отдельно в закрытом репозитории `portfolio-timeweb`; PHP-файлы и конфигурация базы здесь не публикуются.
